# Design Eser — استوديو التصميم الذكي

ارفع **خطة المحتوى** (Excel / CSV / Word / نص) ← الاستوديو يصمم كل منشور **بنفس آلية مهارات Claude** اللي بنيناها
(`guzeleser-post` و`investors-gate`): نفس القوالب، نفس القواعد، نفس فحوصات الجودة، ونفس دقة التصدير —
والذكاء الاصطناعي يشتغل عبر **RadoxAI** مع **موجّه ذكي** يختار أرخص موديل يكفي لكل خطوة.

| | |
|---|---|
| **الهويات** | Güzel Eser (بوست 4:5 + ستوري 9:16، تركي) · بوابة المستثمر (منشور مفرد، كاروسيل، ستوري أخبار، غلاف ريل، عربي) |
| **المدخلات** | Excel/CSV بدون أي توكن (تقويم بوابة المستثمر الأصلي ينقرأ كما هو) · Word/نص/لصق ← موديل رخيص يستخرج المنشورات |
| **الصور** | قص الأشخاص: سكربت المهارة محلياً (فوتوشوب + BiRefNet) ← وإلا BiRefNet/MODNet داخل المتصفح |
| **التعديل** | بالكلام («اختصر العنوان») كرقعة صغيرة · نقد بصري بموديل رؤية مع إصلاح بضغطة · تحرير spec.json مباشرة · تراجع |
| **التصدير** | PNG بـ 2× / 3× (كروم السيرفر = نفس `render.js` بالمهارة) + `spec.json` + `caption.txt` بملف ZIP |

---

## التشغيل

```bash
npm install
npm run sync        # يسحب المحركات من %USERPROFILE%\.claude\skills (قوالب + خطوط + شعارات + مراجع)
npm run dev         # http://localhost:3000
```

ثم من **الإعدادات** حط مفتاح RadoxAI (`cc_…`) — أو بملف `.env.local`:

```ini
RADOX_API_KEY=cc_xxx
RADOX_BASE_URL=https://radoxai.com/v1
APP_PASSWORD=          # لو الموقع منشور على سيرفر — يمنع أي أحد يستخدم مفتاحك
SKILLS_DIR=            # افتراضياً %USERPROFILE%\.claude\skills
CHROME_PATH=           # يكتشفه تلقائياً (كروم/إيدج)
PYTHON_CMD=py -3.11    # بايثون المهارات للقص المحلي
```

> **بعد أي تطوير للمهارات** شغّل `npm run sync` — الموقع يرسم بالقوالب الجديدة فوراً.

## كيف يشتغل

```
الخطة ──► قراءة (Excel: صفر توكن · نص: موديل رخيص) ──► منشورات
                                                        │
الصور ──► وصف رؤية مرة وحدة (يُحفظ كنص) ─────────────────┤
                                                        ▼
                     الموجّه يختار الموديل ──► spec.json (نفس صيغة المهارة) ──► تحقق ✗ ← تصعيد لموديل أقوى
                                                        │ ✓
                                                        ▼
       render-host.html  ◄── نفس templates/post.html و slide.html من المهارة (window.DATA / window.render)
          ├─ معاينة حيّة بالمتصفح + فحص المحرك (QC)
          └─ تصدير: كروم السيرفر (puppeteer، 2×/3×) أو التقاط من المتصفح
```

### الموجّه الذكي (توفير التوكن)

| المهمة | الدرجة الأساسية | الموديل الافتراضي | ليش |
|---|---|---|---|
| قراءة الخطة (نص) | 0 | `deepseek-v4-flash-0731` ($0.12/M) | استخراج منظم بلا إبداع |
| وصف الصور | 1 | `gpt-5.6-luna` ($0.36/M) | أرخص رؤية — والوصف يُخزّن ويُرسل كنص بعدين |
| بناء التصميم | 2 | `gemini-3.7-flash` ($1.24/M) | يلتزم بمخطط المحرك ولغته سليمة |
| تعديل بأمر | 0 | `deepseek-v4-flash-0731` | رقعة JSON صغيرة بس (مو التصميم كامل) |
| نقد التصميم | 2 | `gemini-3.7-flash` | رؤية + JSON |

- **التعقيد يرفع الدرجة**: كاروسيل ≥ 5 شرائح، محتوى طويل.
- **التصعيد عند الفشل**: رد مو JSON / ما يطابق قواعد المحرك (مثلاً عنصرين ثانويين بـ Güzel Eser، أو `footbar` المرفوض) ← نفس الطلب لدرجة أعلى (`claude-sonnet-5` ← `claude-opus-5.5`).
- **وضع الميزانية**: اقتصادي (درجة أقل + بدون أمثلة) · متوازن · جودة (درجة أعلى + سجل ذوق العميل الحي من المهارة).
- **كاش الردود** (IndexedDB): نفس الطلب = صفر توكن. **تثبيت يدوي** لأي مهمة من الإعدادات.
- **سجل الاستهلاك**: كل طلب بموديله وسببه وتوكناته وتكلفته، ونسبة التوفير مقابل استخدام Opus لكل شي.
- الأسعار والقدرات تتحدّث تلقائياً من `GET /v1/models`.

## النشر

الريبو **عام**، فـ `public/engines/` (الخطوط التجارية Gilroy / Expo Arabic، الشعارات، قوالب العملاء) **ما ترتفع** — تنسحب محلياً بـ `npm run sync`.
للنشر على سيرفر: شغّل `npm run sync` على السيرفر (أو انسخ المجلد)، ثم `npm run build && npm start`، وحط `RADOX_API_KEY` + `APP_PASSWORD`.
التصدير بكروم السيرفر يحتاج Chrome/Chromium على السيرفر؛ بدونه التصدير يصير من المتصفح تلقائياً.

## إضافة هوية/محرك جديد

1. أضفه بـ `scripts/sync-skills.mjs` (المهارة + الملفات).
2. محوّل الرسم بـ `public/render-host.js` (كيف يستقبل القالب البيانات).
3. الدليل المختصر للموديل بـ `src/lib/engines/docs.ts`، والتجهيز (`prepare`) والتحقق (`validateSpec`) بـ `src/lib/engines/index.ts`.

## البنية

```
src/components/                الواجهة (الخطة · المعاينة · التحكم · الصور · الإعدادات · الاستهلاك)
```
